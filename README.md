## Selected Projects

### Agricultural and Community Monitoring Platform — CS-IRCFS

A working prototype for agricultural and community monitoring in Bugesera, Rwanda.

- Built a FastAPI backend with SQLAlchemy data models and PostgreSQL integration.
- Developed planner and management dashboards for crop, irrigation, rainfall, and community reports.
- Implemented incident assignment, status tracking, action histories, and a prioritized planner queue.
- Added searchable tables, management forms, and CSV exports.

**Status:** Prototype with simulated phone reporting and SMS-response workflows.

**Technologies:** Python, FastAPI, SQLAlchemy, PostgreSQL, JavaScript, HTML, CSS.

[View repository](https://github.com/Alliance2k2/cs-ircfs-platform)

### Financial Stability and Economic Crises in Africa

- Analyzed 1,059 country-year observations across 13 African countries.
- Compared logistic regression, random forest, and gradient boosting models for systemic crisis prediction.
- Achieved up to 0.89 ROC-AUC and selected random forest for its precision–recall balance.
- Deployed a Streamlit dashboard for exploring economic indicators and crisis-risk predictions.

**Technologies:** Python, Pandas, scikit-learn, Streamlit.

### Functional Data Analysis in Analysing Malaria Data at Regional and National levels

My master’s research at AIMS Rwanda, supervised by Prof. Fabrizio Ruggeri.

- Applied Functional Data Analysis to represent malaria incidence as continuous functions over time.
- Investigated temporal dynamics, seasonal patterns, and geographical variation.
- Compared functional approaches with traditional statistical methods for time series analysis.

### Last Mile Logistics Delivery Performance Dashboard

- Integrated relational datasets using Python and SQL.
- Applied data cleaning, validation, and feature engineering.
- Built an interactive Streamlit dashboard to explore delivery performance and customer satisfaction.
